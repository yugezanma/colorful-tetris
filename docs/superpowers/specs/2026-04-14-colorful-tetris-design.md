# Colorful Tetris — Design Spec

**Date:** 2026-04-14
**Status:** Approved

---

## Overview

シングルHTMLファイルで動作するカラフルなテトリスゲーム。ブラウザで直接開くだけで遊べる。外部ライブラリ・依存なし。

---

## 技術スタック

| 項目 | 選択 |
|---|---|
| 実装形式 | シングルファイル (`tetris.html`) |
| 描画 | HTML5 Canvas API |
| ロジック | Vanilla JavaScript |
| スタイル | CSS (インライン) |
| 依存 | なし |

---

## ゲーム仕様

### ボード
- サイズ: 10列 × 20行
- セルサイズ: 30px（canvas全体: 300×600px）

### テトリミノ（7種）
標準SRS（Super Rotation System）に基づく7種のピース：

| ピース | 形状 | グラデーション色 |
|---|---|---|
| I | 横4マス | 赤 → オレンジ |
| O | 2×2正方形 | 黄色 → 黄緑 |
| T | T字型 | 緑 → シアン |
| S | S字型 | 水色 → 青 |
| Z | Z字型 | 青 → 紫 |
| J | J字型 | 紫 → ピンク |
| L | L字型 | ピンク → 赤 |

### 操作
| キー | 動作 |
|---|---|
| ← / → | 左右移動 |
| ↑ | 回転（時計回り） |
| ↓ | ソフトドロップ（高速落下） |
| Space | ハードドロップ（即座に着地） |
| Enter | ゲーム開始 / リスタート |

### ゲームルール
- ピースは一定間隔で自動落下（初期: 1000ms/行）
- 横一列がすべて埋まったらライン消去
- スコア: 1ライン=100点、2ライン=300点、3ライン=500点、4ライン=800点
- ボード上端にピースが置けなくなったらゲームオーバー
- レベルシステムなし（シンプル版）

### ビジュアル
- 各テトリミノはキャンバス描画時にグラデーション塗りつぶし
- ゲームボードは暗い背景色（#111）
- グリッド線で各セルを区切り表示
- スコアはボード上部に表示

## スコープ外（今回は含めない）

- ゴーストピース（落下先表示）
- NEXTピース表示
- HOLDピース
- ハイスコア保存
- サウンド
- アニメーション（ライン消去エフェクト等）
- レベル・スピードアップ
- モバイル対応

## バグ確認・リファクタリング方針

実装後に以下を確認する：

1. **バグチェック**: 壁抜け・床抜け・回転時の境界外判定・ライン消去ロジック
2. **リファクタリング**: ゲームロジック・描画・入力処理を関数単位で明確に分離
3. **コード品質**: マジックナンバーを定数化、重複排除
